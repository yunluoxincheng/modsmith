# Research Notes

This directory contains background research notes for ModSmith AI planning.

Research notes are not canonical product requirements, architecture contracts, or implementation specifications. When a research finding becomes a project decision, move the decision into the matching stable document under `docs/overview/`, `docs/architecture/`, `docs/specs/`, `docs/generation/`, or `docs/engineering/`.

## Reports

| Report | Use |
|---|---|
| `ai-agent-terminology-and-cache-hit-rate-optimization.md` | AI, RAG, agent, and cache terminology with practical cache hit-rate optimization guidance. |
| `ai-agent-and-cache-systems-engineering-research.md` | Engineering-oriented AI agent and cache system research, including architecture patterns, evaluation, observability, and cache strategy. |
