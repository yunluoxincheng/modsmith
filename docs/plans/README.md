# Development Plans

This directory contains execution plans for ModSmith AI.

Plans are intentionally separated from stable architecture and specification documents. They may be updated as implementation progresses, while the stable contracts under `docs/specs/`, `docs/adapters/`, and `docs/architecture/` should change through the OpenSpec workflow when public behavior or generated output changes.

## Current Plan Documents

| File | Purpose |
|---|---|
| `00-roadmap.md` | High-level product and engineering roadmap. |
| `01-development-plan.md` | Phase-based implementation plan migrated from the v2.4 root docs. |
| `02-phase-0-foundation.md` | Issue-level foundation tasks before Forge MVP generation. |
| `03-phase-1-forge-mvp.md` | Issue-level Forge 1.20.1 MVP implementation tasks spanning the relevant development phases. The filename is historical and should not define a separate phase numbering system. |
| `04-implementation-roadmap.md` | Practical implementation order, risk tiers, texture strategy, UI/CLI/Desktop boundaries, and GUI deferral rules. |

## Rule

Keep planning documents practical and easy to revise. Do not place stable contracts, schemas, or template rules here.
