# Quilt Template Placeholder

This directory is intentionally a placeholder.

Do not add Quilt template files until:

1. The target Minecraft version is selected.
2. The Quilt Loader version is pinned.
3. The Quilt Gradle plugin and mappings strategy are confirmed.
4. The required API dependencies are pinned.
5. The metadata format is verified.
6. The a minimal Quilt project builds successfully inside the sandbox.
7. The a Quilt target profile schema is added.

Forbidden until verified:

- `build.gradle` or `settings.gradle` guessed from memory.
- Loader metadata files guessed from another version.
- Java entrypoint or registration code.
- Copied templates without source notes and sandbox build verification.

Current status: planned placeholder, not implemented.
