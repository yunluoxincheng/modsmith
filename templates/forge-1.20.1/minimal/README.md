# Forge 1.20.1 Minimal Template Scaffold

This directory is a scaffold for acquiring and normalizing the official Forge MDK. It is not a hand-written authoritative MDK copy.

Canonical source:

```text
https://maven.minecraftforge.net/net/minecraftforge/forge/1.20.1-47.4.10/forge-1.20.1-47.4.10-mdk.zip
```

Required SHA1 from Forge download page:

```text
31133abd261aa4d23672d1820db06ccec80326ad
```

Use `../scripts/fetch-official-mdk.sh` and verify the checksum before normalizing the template.

Do not add Fabric or NeoForge files here.
