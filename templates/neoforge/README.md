# NeoForge Template Placeholder

This directory is intentionally a placeholder.

Do not add NeoForge template files until:

1. The target Minecraft version is selected.
2. The NeoForge version is pinned.
3. The official NeoForge MDK or example project is reviewed.
4. The Java version requirements are confirmed.
5. The Gradle plugin configuration is verified.
6. The a minimal NeoForge project builds successfully inside the sandbox.
7. The a NeoForge target profile schema is added.

Forbidden until verified:

- `build.gradle` or `settings.gradle` guessed from memory.
- Loader metadata files guessed from another version.
- Java entrypoint or registration code.
