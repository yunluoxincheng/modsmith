# Fabric Template Placeholder

This directory is intentionally a placeholder.

Do not add Fabric template files until:

1. The target Minecraft version is selected.
2. The Fabric Loader version is pinned.
3. The Fabric API version is pinned when required.
4. The Fabric Loom version is pinned.
5. The mappings strategy is selected.
6. The a minimal Fabric project is verified with a clean sandbox build.
7. The a Fabric target profile schema is added.

Forbidden until verified:

- `build.gradle` or `settings.gradle` guessed from memory.
- Loader metadata files guessed from another version.
- Java entrypoint or registration code.
- Copied templates without source notes and sandbox build verification.
