# OpenSpec Changes

Create one folder per proposed change.

Example:

```text
openspec/changes/add-forge-basic-item-generation/
  proposal.md
  design.md
  tasks.md
  specs/
    mod-generation/
      spec.md
```

Use OpenSpec for changes that affect ModSpec structure, generated output, generator behavior, API behavior, job states, AI behavior, sandbox behavior, version support, security rules, or user-visible behavior.

Small typo fixes, formatting fixes, comments, and isolated refactors that do not change behavior may skip OpenSpec.
